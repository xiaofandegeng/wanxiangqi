# 图文教学与多端界面改版

## 本轮实际变更

- 首页增加官方英雄立绘，缩短标题，移除栏目 emoji。
- 资料库接入官方卡牌图片，英雄、装备、效果牌、天赋按实体展示；移除卡片上的英文字段清单。
- 英雄详情展示完整官方卡面、技能图标与技能文本；复杂事实改为条目，保留原有等级强化事实。
- 阵容详情将构成表改为图片卡片，保留职责、必需性及替补关系；加入对应官方阵容图解。
- 教学页加入相关英雄卡片，基础课程接入官方对战、棋手、英雄、天赋、能量示意图。
- 结构化教学内容用可读条目代替 JSON；未识别字段仍如实保留，不改变规则与统计。
- 去除共享玻璃模糊与面板阴影，减少圆角，使用中性底色和克制强调色。
- 手机端卡牌分列、图片自适应、导航可横向滚动；桌面使用多列卡牌，阅读页限制行宽。
