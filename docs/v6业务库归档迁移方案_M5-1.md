## 3. 执行流程（获授权后逐条执行）

### 3.1 备份并验证可恢复

```bash
TS=$(date +%Y%m%d%H%M%S)
pg_dump -h 127.0.0.1 -U lhw -Fc wanxiangqi > backup-wanxiangqi-${TS}.dump
shasum -a 256 backup-wanxiangqi-${TS}.dump | tee backup-wanxiangqi-${TS}.sha256
# 恢复验证（恢复到隔离库，绝不回写业务库）
createdb -h 127.0.0.1 -U lhw wanxiangqi_m51_verify_test
pg_restore -h 127.0.0.1 -U lhw -d wanxiangqi_m51_verify_test --no-owner backup-wanxiangqi-${TS}.dump
psql -h 127.0.0.1 -U lhw -d wanxiangqi_m51_verify_test -c "SELECT count(*) FROM players"   # 期望 79
psql -h 127.0.0.1 -U lhw -d wanxiangqi_m51_verify_test -c "SELECT count(*) FROM matches"   # 期望 212
```

### 3.3 计数 / FK / 哈希记录（执行前后各一次，存 `docs/v6_artifacts/m5-1-<ts>-{pre,post}.json`）

```sql
-- 计数（public 与 archive_legacy 分列）
SELECT schemaname, relname, n_live_tup FROM pg_stat_user_tables ORDER BY 1,2;
-- 结构（FK 依赖基线）
SELECT conname, conrelid::regclass, confrelid::regclass FROM pg_constraint WHERE contype='f' ORDER BY 1;
-- 证据/存证哈希（内容寻址完整性）
SELECT count(*), md5(string_agg(sha256, '' ORDER BY sha256)) FROM evidence_blobs;
SELECT record_key, content_sha256 FROM raw_materials ORDER BY record_key;
-- 台账不可变性
SELECT filename, sha256, applied_at FROM schema_migrations ORDER BY filename;
```
