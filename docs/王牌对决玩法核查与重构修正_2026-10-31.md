# 王牌对决玩法核查与重构修正

核查时间：2026-10-31。本文补正 v7 截图方案的领域理解，后续实现以这里的区分为准；不宣称客户端全流程已实测。

## 1. 产品究竟分析什么

本项目服务于**观战者支持选手夺冠**的决策，不是替参赛者配阵容，也不是“棋手竞猜”活动。王牌对决是六名高水平真人选手参与的赛事，存在万象大赛、钻石狂潮两类。必须记录赛事类型和底层玩法，不能把普通排位样本、钻石狂潮局内竞拍收益、观众支持回报混成同一口径。

用户的目标链路是：赛前六人截图 → 确认本场六席 → 查历史与近期表现 → 结合**决策当时已揭示**的信息分析冠军 → 再结合当时报价讨论游戏内钻石支持。冠军概率与支持价值分别计算。席位不是名次，真人昵称不是棋手角色，擅长棋手不是擅长阵容。

## 3. 决策分层与仍需核对的细节

### 第一层：只有六人名单

可以分析账号历史、来源样本、近期表现及历史擅长，但不能默认本场一定选择擅长棋手或常用阵容。只有六席与冠军也能形成冠军二元标签，不必为了判断胜负虚构其余五人的完整排名。均排、前三等指标仍需要相应真实名次。

### 第二层：本场额外信息已经揭示

逐席记录已选棋手、已知玩法；记录禁用阵营。信息未出现就留空，不因作者赛后复盘写了最终阵容就当作支持前已知。

同玩法标签相同只能提示需进一步检查英雄竞争，不能直接判定“撞牌扣10%”；实际英雄组成、公共牌库与卡牌生成方式尚需逐项证据。阵容克制同理，不能拿编辑判断伪装统计结论。

### 第三层：支持报价与收益

记录截图时是否仍可支持、各席返奖率以及截图时间。用户历史原图有“支持1500、返奖率5.6、夺冠赢取8400”，支持该画面是含本金总返奖的解释，但不据此断言所有版本结算都不变。

只有人工对照本场规则确认含本金口径后，展示条件公式：

- 总返奖 = 支持数量 × 返奖倍数 r；净收益 = 总返奖 − 支持数量。
- 单一选手保本要求 p × r = 1，即 p = 1/r。5.6对应约17.9%，**这是要求达到的概率，不是模型预测出的概率**。
- 实际最终返奖率是否随支持变化、何时锁定、取整、追加／撤回、多席支持限制、结束时刻等，当前没有取得足够官方细则，均不得推断。所示阈值仅对输入报价成立，不保证结算收益。
- 用户自己的预算、已支持额度、每席剩余额度、概率校准与报价时效齐全后，才有条件实现分配。当前没有完成这一层。

钻石狂潮本身还有独立的局内资源／收益体系，不能把观众支持公式当作参赛者竞拍收益公式。其规则差异不在本轮未经核查地转换成数值权重。
