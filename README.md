专为腾讯《王者荣耀》自走棋新作**《王者万象棋》“王牌对决 · 钻石狂潮”**模式量身打造的**赛前选手画像、局内流派相克推演与正期望值（Positive EV）智能决策平台**。

平台彻底摒弃单一段位分数的简单假设，深度融合自走棋底层机制（**公共卡池限制**、**同行撞车内卷惩罚**、**食物链相克矩阵**、**吃鸡率 vs 吃烂分率分化**）与全服顶尖王者真实历史战绩大盘，为玩家在 2 分钟“冠军支持”封盘窗口内提供毫秒级、高可解释性的下注决策支撑。

## 🌟 核心特色与功能矩阵

### 1. 自走棋局内沙盘推演与卡池内卷引擎 (`matchup-engine`)
* **公共卡池与同行争抢内卷惩罚**：自走棋高费主 C 在公共牌池总量有限。系统自动检测同场 6 位选手主玩流派的核心牌冲突（如两人都抢弈星/公孙离）。对严重撞车双方施加成型节奏惩罚（吃鸡率扣减）；反之，全场独享卡池的选手自动享有追三星红利加成。
* **食物链相克矩阵 (Counter Matrix)**：
  * **刺客流** (如扶桑刺、男刺)：突脸爆发瞬秒脆皮射手主 C（克制系数 `1.35x`）；
  * **重装坦防刺流** (如玄雍坦射、楚汉重坦)：高坦度反伤与控制，令刺客无法切入（克制系数 `1.40x`）；
  * **法核群体爆发流** (如稷下群雄元素法)：大范围法爆融化物理重装前排（克制系数 `1.35x`）；
  * **完全体九五大后期流**：拖入 8~9 人口完全体神装，具备终结统治力。
* **吃鸡率 (1st) 与 吃烂分率 (Top 3) 的本质区分**：
  * **快攻赌狗流**（如 抖音EZ流儿）：前期锁血稳，前三率高达 75%，但大后期缺乏上限，真实吃鸡率仅 10%；
  * **极限单核流**（如 抖音刺痛）：前期容易崩盘暴毙，但一旦公孙离成型，吃鸡率高达 28%，在高倍率盘面下蕴含极高正期望。

### 2. 钻石支持正期望决策系统 (EV / ROI 精算)
* 结合盘面实时赔率（返奖率）与推演真实概率，计算单注净期望收益：
  $$\text{净期望收益 (EV)} = (\text{推演登顶胜率} \times \text{返奖倍率} - 1) \times \text{本金}$$
* **穿透大众盲从陷阱**：
  * **避开伪热门**：全服断层榜一 `EZ夜余` (18824★) 虽然吃鸡率高达 44%，但大众疯狂跟风导致赔率被压至苛刻的 **1.8x**，单注 EV 为负（亏损风险极大）；
  * **捕捉黄金正期望**：战力巅峰第十人 `DY校长神Gin` (12091★) 吃鸡率 28%，被大众低估给到 **7.1x 极高赔率**，单注 EV 高达 **+91.7 钻（ROI +91.7%）**，被评定为【★ 强烈推荐支持】！

### 3. 电脑模拟器实时雷达 (Live Assistant)
* **极速剪贴板视觉解析**：在 Mac 或电脑模拟器中按快捷键截屏后，在前端直接按 <kbd>Cmd+V</kbd>（或拖拽截图），1 秒内完成内容特征提取、对局匹配与推演；
* **多实战对局一键切换**：支持在 **🔥 巅峰赛 18824★ (EZ夜余/校长神Gin)** 与 **📜 王牌对决 11768★ (白白白白3/一茗)** 之间自由切换；
* **后台 Watcher 服务**：Node.js 原生 SSE 长连接服务，随时监听模拟器画面变动并秒级推送开盘事件。

### 4. 全服王者天梯选手大盘库 (`/roster`)
* 沉淀全服 9000★ ~ 19000★ 核心高分段王者（榜一、大主播、职业选手、民间路人王）；
* 呈现真实吃鸡率、前三率、平均名次、本命英雄与战术风格；
* 支持按段位分、胜率、前三率动态排序，点击任何选手可唤出**逐场复盘流水弹窗**（包含每场名次 1~6、棋手、羁绊、三星装备、存活回合与内卷程度）。

### 5. 全服王牌对决历史对战记录大盘 (`/archive`)
* 完整归纳历史王牌对决流水，每场均完整记录 6 席位名次、所选阵容、返奖赔率与 EV 表现；
* 提供**“触发增量巡检入库”**操作，联动后台巡检守护引擎，实时将模拟器新战局沉淀至主数据库。

### 6. 证据链存证与时序防泄漏审计 (`/admin/verify` & `/models/backtest`)
* 每张对局截图计算 **SHA-256 存证哈希**，确保证据链真实不可篡改；
* 严格遵守**防时序泄漏红线（As-of Time-Cutoff）**：赛前推演算法严格物理隔离赛后数据，禁止未来数据回流。

## 🚀 快速上手与运行指南

### 1. 环境准备
* **Node.js**：`v18.0.0` 或更高版本
* **包管理器**：`npm` 或 `pnpm`

### 2. 启动前端数据站
```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```
启动成功后，浏览器访问：**`http://localhost:5173/`**

### 3. 启动模拟器实时监听守护服务 (可选)
如果您希望开启电脑模拟器自动化截屏监听与 SSE 实时推流：
```bash
# 进入监听服务目录
cd tools/emulator-watcher

# 启动服务 (默认端口 8080)
node index.mjs
```

### 4. 运行全量单元测试与编译检查
```bash
cd frontend

# 运行 18 项核心单元测试 (卡池推演 + 结算模型 + 时序防泄漏)
npm run test

# 生产环境打包与 TypeScript 类型检查
npm run build
```

## 🎮 游戏实战使用流程

1. **进入游戏**：在 Mac 或电脑模拟器中打开《王者万象棋》，进入“王牌对决”或“冠军支持”界面（页面显示 6 位选手、段位分、支持人数及返奖率）；
2. **截取画面**：使用快捷键截取游戏画面（如 macOS 按 <kbd>Cmd + Shift + 4</kbd> 拷贝到剪贴板）；
3. **唤醒雷达**：
   * 打开数据站首页，点击右上角 **“模拟器实时雷达”** 按钮（或直接在页面任意处按 <kbd>Cmd + V</kbd> 粘贴）；
   * 系统将在 1 秒内自动完成图像识别，并载入该场 6 位选手名单；
4. **决策参考**：
   * 查看 **【自走棋沙盘推演与卡池内卷分析】**：明确了解谁与谁在争抢同一套长城/刺客核心卡牌，谁享有全场独家流派红利；
   * 查看 **【单注净期望收益 (EV)】**：优先支持高亮标记为 **`★ 强烈推荐支持`** 的正期望选手，规避赔率倒挂的大众虚火席位；
   * 点击选手昵称可展开查阅其历史成型流派与近期名次流水；
5. **锁定席位**：在游戏内 02:00 封盘倒计时结束前，精准下注钻石支持。
