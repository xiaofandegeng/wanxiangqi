本项目是专为腾讯《王者万象棋》（已于 2026 年 9 月开启全平台公测）“王牌对决 · 钻石狂潮”模式定制开发的**极速实战决策与钻石投注预测工作台**。

### 核心实战痛点与定位：
1. **公测正式版实战对决**：基于万象棋公测版本底层博弈机制、71 位实战认证选手与 39 万局大盘流派食物链建立数值模型；
2. **王牌对决限时 3 分钟生死时速**：在游戏内王牌对决模式中，开盘至封盘**仅有 3 分钟（180秒）支持竞猜窗口**，过后立即封盘锁定；
3. **极致实效性与 3 秒决断**：支持全局截图粘贴（`Cmd+V` / `Ctrl+V`）毫秒级自动填入，3 秒内直出【唯一核心推荐席位】与【严禁下注负期望陷阱】，杜绝盲目跟风亏钻。

## 🌟 核心实战工作台与功能矩阵

### 1. 王牌对决 · 钻石预测决策工作台 (`/`)
* **3 分钟限时封盘实时警报条**：内置动态数字倒计时与状态感知（竞猜开启 ➔ 临界冲刺 ➔ 封盘锁定），并提供极速重置与模拟开盘测试。
* **首屏 3 秒决断指示 Banner**：直接突出标示正期望收益席位（例如 `#2 散修鲤非鱼，EV +49.8 钻，建议仓位 40%`），严禁玩家下注赔率被严重压低的热门陷阱席位。
* **6 席位盘面参数实时交互**：选手联动、体系调整、赔率微调瞬间响应重算，每 100 钻下注净收益与半凯利准则建议仓位一目了然。
* **四重严谨分析依据展开**：详细公开选手历史吃鸡率、大盘 39 万局食物链相克、公共卡池撞车内卷与赔率期望值 EV 算力。

### 2. 真实选手战力天梯大盘 (`/roster`)
* **71 位实战认证选手真实档案**：来源于万象棋大数据平台官方 S1 锦标赛实战选手档案，真实游戏 UID 与锦标赛积分公开可查。
* **基准战力加权与逐局流水下钻**：作为王牌对决 6 席位胜率推演的基准战力输入，支持点击选手查看历史实战流水。

### 3. 阵容食物链相克与胜率依据大盘 (`/lineups`)
* **390,306 场大盘真实聚合**：收录 36 套成型体系，明确标注样本量与置信度。
* **相克食物链拆解**：明确射手破重甲、刺客切射手、重甲克刺客、法爆压重甲的核心对抗规律，提供局内下注指导依据。
* **真实结构解析**：通过适配器真实解析结构化阵容卡片，严格校验登顶率、前三率、平均名次在合法数值区间。
* **失败保护与真实报错**：网络受限或内容异常时报告 FAILED，保留最后有效快照，严禁用假数据覆盖，绝不伪装成功时间。
* **详情路由下钻**：支持 `/lineups/:id` 查看流派构成与观测样本口径说明。

### 4. 历史对战记录归档大盘 (`/archive`)
* **全量事实对局呈现**：按时序归档历史对战，保留 6 席位名次、返奖倍率、支援热度与登顶选手。
* **真实增量巡检**：无新增事实时诚实提示“暂无新增核验对局”，彻底剔除客户端捏造假对局的逻辑。

### 5. 局内机制沙盘推演与客观数据评定 (`LiveRadarModal`)
* **卡池内卷与相克推演**：严格要求完整 6 位选手才启动推演，缺人或未知图片直接阻断推演并引导进入人工录入台。
* **客观中立评定**：生产环境彻底关闭未经 P4 回测验证的 `STRONG_BUY` 等强推荐标签，仅输出中立数据面与机制克制评析。

## 🚀 快速上手与运行指南

### 1. 启动后端业务服务
```bash
cd backend
npm start
```
服务将在 `http://127.0.0.1:8080` 启动，并输出数据库驱动状态与鉴权配置。

运行后端回归测试：
```bash
npm test
```

### 2. 启动前端数据站
```bash
cd frontend
npm run dev
```
前端将在 `http://localhost:5173` 启动。

运行前端全量测试与构建：
```bash
npm test        # 执行 26 项 Vitest 单元与集成测试
npm run build   # 执行 vue-tsc 类型检查与生产构建
```

## 🔒 真实数据闭环与防伪机制

1. **双时间截点防未来泄漏 (Dual-Time Cutoff, F10)**：
   每条比赛记录同时持久化 `match_time`（实际比赛时间）与 `available_at`（系统录入可用时间）。查询赛前特征时严格执行：
   $$\text{match\_time} < \text{cutoff} \quad \text{AND} \quad \text{available\_at} \le \text{cutoff}$$
   即使比赛发生早，若录入系统晚于截点（晚到数据），在截点时刻一律剔除，严防未来信息泄露。

2. **管理接口安全鉴权 (F09)**：
   所有 `/api/v1/admin/*` 写操作必须携带合法 Bearer Token（`Authorization: Bearer wanxiangqi-admin-token-v2`），未授权请求直接 401 拦截。
   服务默认绑定回环地址 `127.0.0.1`，CORS 仅允许本地安全来源，杜绝公开网络随意写入。

3. **三端响应式自适应布局 (F11)**：
   全面统一为现代清爽浅色数据站风格（纯白卡片 `#FFFFFF`、浅灰背景 `#F8FAFC`、深色文字 `#0F172A`、科技蓝 `#2563EB`）。
   顶部导航在窄屏下支持平滑横向滚动，宽表被包裹在独立滚动容器内，确保 375px（移动端）、768px（平板）、1440px（桌面端）均自适应无横向裁切。

## 📑 页面路由一览

* `/`：王牌对决赛程与实战对局（支持日期范围筛选与 URL 双向同步）
* `/roster`：全服选手天梯事实榜（基于已核验战绩复算登顶率与前三率，支持下钻流水）
* `/lineups`：阵容环境大盘（第三方快照聚合，流派观测出场人次）
* `/lineups/:id`：单套阵容核心羁绊与样本说明详情
* `/archive`：历史对战记录事实档案库（支持增量巡检）
* `/models/backtest`：模型评估与回测基线（暂无正式验证结果，展示真实空态）
* `/admin/verify`：证据链存证与人工核验工作台（SHA-256 存证、6 席位持久化、JSON 批量导入）
