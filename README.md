本项目是专为腾讯《王者万象棋》“王牌对决”模式构建的**选手历史战绩归纳、对局席位对比与数据辅助决策平台**。

项目遵循**“可追溯、防泄漏、真实复算”**原则，旨在解决传统玩家仅凭单一段位分数或热门偏见进行决策的痛点，引入自走棋底层机制（公共卡池争抢、流派克制关系、登顶率与前三率分化）以及多维度历史对局复盘，提供理性客观的数据支持。

> **当前工程状态提示**：
> 本系统正处于 **v2 真实数据接入与 UI 改版演进期**（详见 [v2 任务书](./docs/王者万象棋数据站_真实数据接入与UI改版开发任务书_v2.md)）。系统正从“前端原型演示”向“真实持久化后端 + 外部数据源适配 + 克制数据工具 UI”全面迁移。

## 🌟 核心功能矩阵

### 1. 对局席位对比与卡池内卷分析 (`matchup-engine`)
* **公共卡池冲突检测**：自走棋高费核心牌在公共卡池总量受限。当系统检测到同场多名选手主玩阵容核心牌高度重合（例如多人同时争抢刺客或法核核心）时，自动评估卡池挤压惩罚；独享卡池的流派则标注成型优势。
* **流派机制相克矩阵**：收录刺客突脸、重装坦盾、法核群爆等流派克制关系，辅助用户理解对局潜在的克制胜负手。
* **登顶率 (1st) 与 前三率 (Top 3) 分化呈现**：区分“快攻保分流”（前三率高但后期缺乏吃鸡上限）与“单核大后期流”（前期易暴毙但成型后吃鸡率高）。

### 2. 钻石支持期望值精算模型 (EV 精算)
* **期望收益公式**：
  $$\text{净期望收益 (EV)} = (\text{推演胜率} \times \text{返奖倍率} - 1) \times \text{支持本金}$$
* **理性决策参考**：
  * 识别大众跟风导致的赔率倒挂风险（极低赔率席位即使胜率高，长期期望值可能为负）；
  * 发掘胜率稳健但赔率偏高的高价值席位。

### 3. 本机截图快速录入与实时雷达
* **剪贴板截图快速解析**：在 Mac 或电脑模拟器中截取“王牌对决”房间画面后，在前端直接按 `Cmd + V`（或拖拽上传），快速提取 6 位选手特征并调取历史战绩。
* **多实战房间切换**：支持在不同段位/主播的已录入对局中快速切换与复盘对比。
* **Watcher 守护桥**：提供 Node.js 本机截屏监听守护进程，支持 SSE 增量事件推送。

### 4. 选手历史战绩库 (`/roster`)
* 归纳全服高分段选手（大主播、天梯王者、民间路人王）的真实战绩大盘。
* 记录选手的有效样本数、登顶率、前三率、平均名次与偏好英雄。
* 支持点击选手唤出**逐场复盘流水弹窗**（查看每场排名、阵容羁绊、存活回合与卡池内卷程度）。

### 5. 历史对战记录归档大盘 (`/archive`)
* 完整归档历史对战轮次，每场均保留 6 席位名次、所选阵容、返奖赔率与实际结算。
* 提供增量更新与数据沉淀入口。

### 6. 数据审计与防时序泄漏设计 (`/admin/verify`)
* **证据链存证**：对局截图计算 SHA-256 哈希存证，确保证据链可回溯。
* **严格防泄漏（As-of Cutoff）**：赛前特征严禁引入开赛时间点之后的数据，杜绝未来信息回流。

## 🚀 快速上手与运行指南

### 1. 环境准备
* **Node.js**：`v18.0.0` 及以上（推荐 v20+）
* **包管理器**：`npm` 或 `pnpm`
* **可选环境**：PostgreSQL 14+（用于持久化服务）

### 2. 启动前端项目
```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```
启动成功后，浏览器访问：**`http://localhost:5173/`**。

### 3. 启动本机截图监听桥 (可选)
如果需要配合电脑模拟器进行截图自动录入：
```bash
cd tools/emulator-watcher
node index.mjs
```
默认监听端口为 `8080`，可通过 `http://localhost:8080/events` 提供实时 SSE 事件流。

### 4. 运行单元测试与生产构建
```bash
cd frontend

# 运行 18 项核心单元测试（卡池引擎、时序防泄漏、结算规则）
npm run test

# 生产环境打包检查 (含 TypeScript 严格类型检查)
npm run build
```

## 🎮 业务使用流程（截图录入与对比）

1. **截取房间画面**：在游戏或模拟器中进入“王牌对决”房间（显示 6 位选手、段位分与返奖倍率），使用系统快捷键截图复制到剪贴板；
2. **唤起截图录入**：在前端首页点击右上角 **“模拟器实时雷达”** 按钮（或直接按 `Cmd + V` 粘贴）；
3. **核对席位与数据**：
   - 查看 6 位选手的段位、有效历史样本与真实登顶/前三率；
   - 查看 **【卡池冲突分析】**：查看核心英雄是否遭遇同行争抢；
   - 查看 **【单注净期望收益 (EV)】**：综合胜率与返奖倍率，规避负期望陷阱；
4. **深入复盘**：点击任意选手昵称，可展开查阅该选手的详细战绩流水。

## 📋 页面路由与功能一览

| 路由地址 | 页面名称 | 主要职责与内容 |
| :--- | :--- | :--- |
| `/` | **今日对决** | 今日王牌对决赛程轮次列表，按时间区间展示场次与录入状态 |
| `/events/:id` | **对局深度对比** | 单场 6 席位对比看板、卡池冲突分析、期望值模拟器与存证记录 |
| `/roster` | **选手战绩大盘** | 全服已收录选手战绩大盘，支持多维度排序与逐场流水下钻 |
| `/archive` | **历史对战记录** | 历史实盘对局归档，支持夺冠阵容复盘与增量更新 |
| `/lineups` | **阵容环境大盘** *(v2 建设中)* | 外部阵容样本量、登顶率、前三率与核心羁绊大盘 |
| `/models/backtest` | **模型回测评估** | 历史算法预测对比均匀基线的准确率与增益评估 |
| `/admin/verify` | **证据链核验** | 截图存证 SHA-256 审计与录入校对工作台 |
